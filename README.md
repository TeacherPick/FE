# TeacherPick 로컬 웹 화면

Python 기본 HTTP 서버로 실행하는 로컬 웹 UI입니다. 브라우저 화면과 라우팅은 HTML·CSS·JavaScript로 구성되어 있습니다. 페이지 이동은 `#/login`, `#/community` 형태의 hash router를 사용합니다. 커뮤니티 영역은 일반 게시판이 아니라 강사가 등록한 프로그램 게시판으로 구성했습니다.

## 실행

```bash
python3 app.py
```

브라우저에서 <http://127.0.0.1:8000>을 여세요. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

## 포함된 화면과 흐름

- 교사·강사 회원가입, 로그인, 비밀번호 찾기·변경, 로그아웃 확인
- 강사 검색과 강사 프로필의 등록 수업·리뷰 조회
- 프로그램 게시판 검색·페이지네이션·정렬, 프로그램 등록·수정·삭제 확인, 핵심 기술·첨부 자료·댓글·대댓글
- DM 대화, 읽지 않은 메시지 표시, 브라우저 내 파일 저장·열기, 대화방 나가기 확인
- 리뷰 작성·수정·삭제·정렬
- 관리자 계정 상세·삭제, 프로그램 게시물 삭제 확인, 활동 로그, 관리자 로그아웃 확인

학생 계정·학생 추천 홈, 강사 고급 필터, 일반 커뮤니티 게시물, 프로그램 임시 저장, 관리자 KPI 대시보드, 로그인 유지 체크박스는 포함하지 않습니다.

## 실서비스 적용 전 제한 사항

요청에 따라 외부 API는 연결하지 않았습니다. 이 프로젝트는 로컬 화면과 브라우저 동작 검토용이며, 계정과 콘텐츠는 브라우저 `localStorage`에 저장되어 기기 간 공유되지 않습니다. 로그인·관리자 권한도 브라우저 상태로 처리하고, 관리자 데모 계정은 `admin / admin1234`입니다. 비밀번호 찾기 인증번호는 로컬 미리보기 화면에만 표시되고 메일은 발송하지 않습니다. 메시지 첨부파일은 IndexedDB에 저장되어 같은 브라우저에서 열 수 있지만 서버로 업로드되지 않아 다른 기기와 공유되지 않습니다. 이전 버전에서 이름만 저장한 첨부파일은 다시 첨부해야 열 수 있습니다.

따라서 공개 서비스로 쓰기 전에는 서버 측 인증·권한 검사, 공유 데이터베이스, 실제 메일 인증, 파일 저장소, HTTPS 배포, 운영자 자격 증명 관리가 필요합니다. 현재 코드를 공개 운영 환경에 그대로 배포하거나 실제 개인정보·비밀번호를 넣지 마세요.
